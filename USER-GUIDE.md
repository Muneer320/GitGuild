# GitGuild user guide

The current local walkthrough is in [USAGE.md](USAGE.md). It covers repository token creation, minting, redemption, YES/NO positions and claims with Hardhat test ETH.

Start with [SETUP.md](SETUP.md). The browser app runs at http://localhost:3000 after the local node and contracts are running. Contract outcomes are owner supplied; GitGuild does not verify GitHub activity.
